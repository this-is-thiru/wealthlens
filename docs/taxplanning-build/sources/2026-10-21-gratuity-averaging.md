# Gratuity: the ten-month averaging period (W-152, 2026-10-21)

Why this file exists: W-152 makes the period a gratuity's salary is averaged over a rule row (`RET-GRATUITY-AVERAGING`),
and its TY 2025-26 version needs the instrument that introduced 1961 s.10(10)(iii)'s words. The repo had sourced only
the s.10(10) Explanation (`sources/2026-10-16-introduced-by.md:78`; `SAL-SALARY-FOR-GRATUITY`).
