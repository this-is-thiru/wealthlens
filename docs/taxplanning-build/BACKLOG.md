**An item not in this file is finished**; its record is its D-row in [`DECISIONS.md`](DECISIONS.md). Ids are kept (rule data,
code and tests cite them); the phases are new (W-435, D-1051). Earlier tracking — the status board of every item, the work items
with their history, the parked register — is in git tag `docs-history-m5`
(`git show docs-history-m5:docs/taxplanning-build/STATE.md`, `…/03-WORK-ITEMS.md`, `…/PARKED-ROWS.md`).

An item finished leaves its row here in its own commit. A new item is a row in the phase it belongs to. `StatusBoard` reads the
`Status` column (`CoverageBacklogTest`, `NotIncludedWaitsTest`, `FinishedPlanTest`).
