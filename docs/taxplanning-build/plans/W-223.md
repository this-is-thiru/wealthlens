### Choices (recommended first)

**C1 — when the entered figure stands.**
- **(a) Unresolved with a nil total.** The engine priced nothing it stands behind, so the entered figure stays. A `PROVISIONAL` result with a figure, and a resolved nil such as a corporate action's exemption, still replace it.
- (b) Any unresolved resolution, including a `PROVISIONAL` figure: throws away computed charges.

**C2 — what the tax side does with a kept charge (row 4).**
- **(a) Keep the refusal, correct its wording.** The charge's kind is unknown, so no figure is safe; "record those trades again" cannot help a no-card asset, so it will say so. **Cost:** one sold bond with an entered charge blocks that user's year in the summary, loudly, until a coded entry exists.
- (b) Pass it as `MISC`, not deducted (`CG-CHARGE-MISC`): the year computes, with the gain possibly too high and only a trace line saying so.

**C3 — the sale side (row 5).**
- **(a) One line in the register's "Noted".** It fails the cap's test only if it stays silent; I would check that at build and give it a row if so.
- (b) Fix it here: wider than the row.
