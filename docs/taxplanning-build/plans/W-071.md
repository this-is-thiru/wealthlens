## Plan for W-071 — perquisite values, both years

**What this item is for (one sentence):** value the benefits an employer provides other than in money —
accommodation, cars, services, loans, meals, gifts, securities and the rest — so that they enter income under
"Salaries" as the Acts and Rules value them, for both tax years.

**This plan does not build anything yet. It proposes splitting W-071 and W-072 into pieces you can approve one at a
time (C1), because the item is far larger than one reviewable change, and it names the sourcing each piece needs.**

### Findings

1. **W-071 as written ("perquisites.json both years") is dozens of rules and several input shapes.**
   - Each perquisite has its own facts: city population, car engine size and use, loan balance and rate, meal value
     per meal, gifts in the year, and so on.
   - Each has its own valuation and conditions.
   - The house pattern since W-067 (inputs, rows and node wiring together, per concept, both years) doesn't fit one
     item.
2. **Splitting W-071 "data" from W-072 "node" no longer matches how the engine is built.** Every salary item since
   W-061 shipped its rows with the node that reads them, so that I3 (every rule evaluated) holds at each commit.
3. **Sourcing is uneven:**
   - **Accommodation:** both years read. TY 2026-27 is r.15 Table I; TY 2025-26 is r.3(1) as substituted in 2023.
   - **The thresholds:** TY 2026-27 read (r.17, r.19). TY 2025-26 is an unseen 2025 Rules amendment.
   - **Everything else:** TY 2026-27 read; TY 2025-26 not.
