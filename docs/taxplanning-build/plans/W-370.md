## Plan for W-370 — log a caller's mistake below ERROR

> Planned in session 115 (2026-11-22), next by D-899. Found by W-366b / c row 7 (D-896). **Stop point: nothing is built until the owner
> answers C1 – C2.**

**What this item is for (one sentence, in my own words):** the log's ERROR lines mean that something failed, not that a caller sent a wrong
request, so a deploy's "no ERROR" check and anyone reading the log see real failures only.

### What the code does today

| | | Where |
|---|---|---|
| Every handler | calls one `log(ex)`, which is `log.error(ex.getMessage(), ex)`: ERROR with the stack trace, whatever the answer | `ControllerAdviser.java:231` – `:233` |
| Handlers | 400 ×7 handlers (`IllegalArgumentException`, which `BadRequestException` extends, unreadable body, missing parameter, type mismatch, missing part, upload too large, invalid body), 401, 403, 404, 405, 415, 429, 409 (`TradeCollisionException`), 503 (`ServiceUnavailableException`), 500 (`Exception`) | `ControllerAdviser.java:40` – `:159` |
| Seen at the deploy | each database's row 7 counted 4 ERROR lines: three 404s for the removed routes and one 400 for a trade without a stock, all deliberate | run log, W-366b / c row 7 |
| Tests on the level | none. `RequestIdIntegrationTest.refusal_whenLogged_carriesTheIdItsAnswerCarries` captures the adviser's events at any level (`:58`), and `LogCapture` (testsupport) reads `warnings()` / `errors()` | grep |

### Decisions (for approval with this plan)

- **C1 — a caller's mistake (every 4xx).** **C1a (recommended):** WARN, the message only and no stack trace, since the trace of a refused
  request names no fault. **C1b:** INFO.
- **C2 — the two 4xx/5xx that are not the caller's mistake.** **C2a (recommended):**
  - **503** (an operator switched the charge engine off): WARN, a deliberate state and not a failure.
  - **409** (a trade collided on every retry): WARN, an answer the caller can retry.
  - **500:** stays ERROR with the stack trace.
  - **C2b:** both at ERROR.

### Files (if C1a, C2a)

- **Modify:** `ControllerAdviser`. `log(ex)` becomes `refused(ex)` (WARN, message) for every handler but the 500, which keeps
  `log.error(…, ex)`.
- **Create:** cases in `ControllerAdviserTest`, red first:
  - a 400 (`IllegalArgumentException`) and a 404 log one WARN and no ERROR;
  - the 500 logs one ERROR carrying the exception.

  They use `LogCapture.on(ControllerAdviser.class)`.
