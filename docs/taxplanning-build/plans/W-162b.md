## Plan for W-162b — `portfolio` stops storing deductibility

**What this item is for (one sentence, in my own words):** since W-162a nothing in the tax path reads the
`deductible_buy_charges` / `deductible_sell_charges` stored on each trade outcome; this item stops writing them, drops
them from the entity, the recorder's context and the holdings response, and removes them from the rows already stored,
so `portfolio` keeps no figure derived from a year's law (D-375; audit T4).

**Small: about 20 lines of main code removed, about 100 added for a one-time operation, one API field removed, one
R15 runbook entry.**
