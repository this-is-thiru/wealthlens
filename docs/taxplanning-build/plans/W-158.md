### Risks or ambiguities

1. **Refusals move.** As in W-155c2, a wrong input is then refused at computation, naming the row, not at
   construction. A test that builds a record with a wrong combination and expects the constructor to throw has to
   become a computation test. Each sub-plan counts them.
2. **I have read the rows' fact names, not each row whole.** "Derivable from the rows" is checked fact by fact in
   each sub-plan. A fact no row reads at all, such as `higherOfficialUse` for expenses, is refused as unread there,
   as W-155c2 did.
