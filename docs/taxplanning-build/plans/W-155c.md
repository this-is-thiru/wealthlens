## Plan for W-155c — the notified entries' bases, B, and each entry's facts by rule data

**What this item is for (one sentence, in my own words):** three entry tests remain in Java after W-155a and W-155b.
They decide which bases a notified entry's least-of reads, which earlier amounts form the aggregate's B, and which
facts a payment may carry. This item makes each follow from the facts given and from rows, not from `RetirementEntry`
(D-336 R4 – R6; audit P5).

**This plan raises C1 – C4. C1 is a split: the whole item is over §7, so the build below is W-155c1 only.**
