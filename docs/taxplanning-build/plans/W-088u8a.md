## Plan for W-088u8a — tax-policy seeding as a `SUPER_USER` operation

**What this item is for (one sentence):** the TY 2025-26 tax policies stop being written at boot by
`@PostConstruct`, as "unknown" and with failures only logged. They are written only when a `SUPER_USER` asks:
dry run first, the caller recorded on every policy, and a failed part reported as an error that names its file
(D-280, D-281; C1a of `plans/W-088u8.md`).

### Design

1. **`PolicySeederService.seed(boolean dryRun)` returns `PolicySeedReport`**, and `@PostConstruct` is removed.
   - Per part (`SLAB_NEW_REGIME`, `SLAB_OLD_REGIME`, `PERQUISITE`, `ALLOWANCE_CATALOGUE`, `ALLOWANCE_LIMITS`) it
     reports the file, the outcome (`SEEDED`, `WOULD_SEED` in a dry run, or `ALREADY_ACTIVE`) and the number of
     documents.
   - Nothing is saved in a dry run.
   - The parts keep their order and their skip rule. `"2025-26"` and the file paths stay as they are: this item
     changes who triggers the seeding, not what is seeded.
2. **A failed part (C1a):** `IOException` and `JacksonException` are caught by name and rethrown as
   `IllegalStateException("<file>: <reason> — the parts before it are seeded; fix the file and seed again")`.
   `ControllerAdviser` answers 500. Parts already seeded stay, and a re-run skips them. `catch (Exception)` is gone,
   so its baseline suppression (`checkstyle-suppressions.xml:66`) is removed; the baseline may only shrink.
3. **`POST /tax-planning/admin/policies/seed?dryRun=true|false`** goes on `TaxPlanningController`.
   - It is `@PreAuthorize("hasRole('SUPER_USER')")`, and `dryRun` defaults to true.
   - It returns the report, with the caller's name in it. The saved documents carry the caller through the
     existing auditing.
4. **`AbstractIntegrationTest`:** a `@BeforeEach` seeds through `PolicySeederService.seed(false)`. It is idempotent,
   so after the first test each call finds everything `ACTIVE` and writes nothing. Its comment (`:38–42`) is
   corrected.
5. **Runbook (R15):**
   - §1.2, "seeding at startup", is replaced by **§2.0, a manual step: required on a fresh database, before any tax
     computation.** It is the dry run, then `?dryRun=false`, then read-back by
     `GET /tax-planning/admin/policies?taxYear=2025-26` and the four counts.
   - On a database that already holds the policies, the dry run reports `ALREADY_ACTIVE` for every part, so nothing
     is to be done.
   - WL-A-2 is republished.

## Revision 1 — idempotent after a partial run (owner: "make sure the scripts are idempotent"; D-282)

**What was wrong with the plan.** It kept the seeder's rule of skipping a whole part when any `ACTIVE` document
exists. That is idempotent after a full run, but **not after a partial one**. Say the allowance catalogue fails
after saving 20 of its 39 entries: a re-run finds active entries, skips the part, and the other 19 are never
seeded.

**Revised design (replaces design 1's skip rule):**
- Each part seeds **per document**, skipping only documents already present under their natural key. A re-run
  after any failure therefore completes the seed, and a run after a complete one writes nothing.
- The natural keys, checked unique in the shipped files:

  | Part | Key |
  |---|---|
  | slab | `(tax_year, regime_type, ACTIVE)` |
  | perquisite | `(tax_year, ACTIVE)` |
  | catalogue | `(code, tax_year, regime_type)`, 39 unique (`findByCodeAndTaxYearAndRegimeType` exists) |
  | limits | `(allowance_code, tax_year, regime_type, employer_type)`, 14 unique. Without `employer_type`, NPS_EMPLOYER's GOVT / PSU / PRIVATE rows collide |

- The report says per part how many were seeded, would be seeded, or were already present.

**New case:** with the catalogue partly seeded (20 of 39 present), a run seeds the other 19, and a second run
seeds 0 (idempotence after a partial run).

**Remove after use (owner, D-282):** this endpoint is one-time per database. **W-088u9b** (YouTrack WL-30) removes
it once the run is logged for every database.

**Post-deployment actions:** as above (§2.0), plus the runbook states that it is idempotent, including after a
partial run.
