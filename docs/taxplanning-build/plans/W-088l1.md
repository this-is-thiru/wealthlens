### The greps (run from `backend/src/main/java/com/thiru/wealthlens/taxengine`, kept with their counts)

```
G1 date literals        grep -rnE 'LocalDate\.of\(|Month\.[A-Z]+|MonthDay\.of|Year\.of' .
G2 numeric literals     grep -rnE '[^A-Za-z_.][0-9]{3,}[^0-9]|[0-9]+\.[0-9]+|BigDecimal\.valueOf\(' .   (comments excluded)
G3 money / rate makers  grep -rnE 'Money\.of\("|Rate\.of\(|new Rate\(|percent\(' .
G4 switches             grep -rnE 'switch \(|case [A-Z_]+(,| ->|:)' .
G5 enum sets and maps   grep -rnE 'EnumSet\.|EnumMap|Set\.of\(|Map\.of\(|List\.of\([A-Z][A-Za-z]+\.[A-Z_]+' .
G6 enum comparisons     grep -rnE '== [A-Z][A-Za-z]+\.[A-Z_]{2,}|\.equals\([A-Z][A-Za-z]+\.[A-Z_]{2,}\)' .
G7 static constants     grep -rnE 'static final [A-Za-z<>, ]+ [A-Z_]+ =' .
G8 string codes         grep -rnE '"[A-Z][A-Z0-9_]{3,}"' .
```

Each hit gets a verdict line: finding (kind, the law if a rule row or `sources/` names it, else "law not identified")
or not a finding (the reason: arithmetic, an id constant, a rule-set id, a trace word, a state of the code's own).
Hits that share a cause are grouped in the table with a count, so the section stays readable; the raw grep output is
kept in the section's appendix.
