## Plan for W-408 — keep an uploaded trade's execution time in `asset_request_json`

> Planned in session 123 (2026-11-26); placed by D-975 (found planning W-337g2b2). **Stop point (Stage 2 EXPLAIN).**

**What this item is for (one sentence, in my own words):** make the stored form of a held trade's request keep the execution
time the upload read, so redriving it records the time it had — as MongoDB did — while API callers still cannot send it.

**The defect (read this session):**
- `AssetRequest.orderExecutionDateTime` carries `@JsonIgnore` and `@JsonFormat(pattern = TCollectionUtil.DATE_TIME_FORMAT)`
  (`AssetRequest.java`; `DATE_TIME_FORMAT = "yyyy-MM-dd'T'HH:mm:ss"`, `TCollectionUtil.java:21`).
- Only the Excel upload sets it, from the cell's value (`AssetRequestParser.java:210`, `setBrokerOrderTime`).
- `orderExecutionDateTime()` reads it first (then `orderExecutionTimestamp`) and returns `TLocalDateTime.atUtc(it, timezoneId)`;
  `asTransaction()` (redrive, V1) and `PortfolioService` lines 445 / 453 (order-time quantities) use that.
- `AssetRequestConverter` (`TransactionEntity.java:168`) writes the request with a default `JsonMapper`, which honours
  `@JsonIgnore` — the value never reaches `asset_request_json`; MongoDB (Spring Data ignores `@JsonIgnore`) kept it.
- Nothing hosted runs the PostgreSQL build yet (prod and staging are `m1.6.1` on MongoDB), so no stored row has lost it;
  only the copier (W-337g2b2) would carry the loss over.

### Decision (for approval)

- **C1 — how the stored form keeps it.** **C1a (recommended):** a Jackson mix-in, `StoredAssetRequest` (in `portfolio/entity`,
  beside the converter), that un-ignores `orderExecutionDateTime` (`@JsonIgnore(false)`, `@JsonProperty`); `AssetRequestConverter`'s
  mapper registers it. The field's `@JsonFormat` still applies; `AssetRequest` and the API are unchanged. W-337g2b2's walk
  registers the same mix-in for `AssetRequest`, so the copier writes the stored form. **C1b:** drop `@JsonIgnore` from the field —
  API callers could then send the time as text, a change to the request contract (`ApiCollectionContractIntegrationTest`, the
  OpenAPI spec); not recommended. **C1c:** a separate stored record copied field by field — two shapes to keep in step; not
  recommended.
