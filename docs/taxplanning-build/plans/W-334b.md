**Row 5 — generate and store the keys** (owner's terminal; 6.0.2, §0.5 step 1). Per environment — dev, staging, prod —
three runs of `openssl rand -base64 32`: `TAX_DATA_KEY`, `TAX_DIGEST_KEY`, `JWT_SECURITY_KEY`. Store all nine in the

exported, paste only this:
```bash
for v in TAX_DATA_KEY TAX_DIGEST_KEY JWT_SECURITY_KEY; do printf '%s %s %s\n' "$v" "$(printenv $v | base64 -d | wc -c | tr -d ' ')" "$(printenv $v | shasum -a 256 | cut -c1-12)"; done; printenv PRIVACY_CONTACT | wc -c
```
- Expect: `32` on each line; nine distinct 12-character prefixes across the three environments; a contact length above 1.
- Stop if: any length is not 32, any prefix repeats (a shared key — 6.0.2 forbids it), or the contact is empty.
  Way back: generate again; nothing has used them yet.
