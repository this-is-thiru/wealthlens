**What this item is for (one sentence, in my own words):** before 38 more collections are ported, prove on the two smallest modules
that JPA + Flyway on PostgreSQL can hold what MongoDB holds today: the encrypted and searchable fields, an embedded list, an atomic
conditional update, an expiry without a TTL index, a transaction, money as `double` and times in UTC, all exactly.

### The Postgres version — settled, not a decision (D-936, read directly this session)

Both hosts already exist and both answered `SELECT version()` directly in `plans/W-337h.md`'s rows: Neon's `production`
branch and Aiven's `wealthlens` service are each **PostgreSQL 18.7**. Unlike Oracle's Always Free MySQL (which auto-upgraded

docs were read this session for an auto-upgrade policy; nothing says the version will move under the pin, but nothing rules
it out either. The tests pin Testcontainers to Postgres **18** and re-read `SELECT version()` on both hosts before each later
sub-item if a test ever behaves unexpectedly.

### Decisions (for approval with this plan)

- **C1 — which Postgres the tests run on. Settled, not a decision:** 18 (both hosts agree, read directly — see above). The
  original MySQL-era question ("which MySQL, since Always Free tracks a moving target") does not apply.
- **C2 — how the probe lives beside MongoDB on branch `w-337`.** **C2a (recommended):** kept: `insurance` and `auth` really move
  to JPA on the branch; MongoDB stays primary for every other module; JPA gets its own transaction manager, named, used by the
  two modules' services. Until W-337f ends the split, an account erasure writes the two stores in two transactions — on the
  branch only (D-928 C2a keeps master whole), and the affected tests are listed in the report. **C2b:** a throwaway spike, only
  the ADR kept; W-337c then does the same work again.
- **C3 — the refresh-token expiry with no TTL index.** **C3a (recommended):** expired rows are deleted on each sign-in
  (`DELETE … WHERE expires_at <= now`, indexed), cheap and with no scheduler, which the app runs without locally (W-336);
  a stale row already signs nobody in (`RefreshTokens.java:70`). **C3b:** a job beside the tax jobs.

### Build (if C2a – C3a)

On branch `w-337` from `review/taxplanning`:
1. **Dependencies:** `spring-boot-starter-data-jpa`; `org.postgresql:postgresql` (runtime, Boot-managed, no version to
   pin); `spring-boot-starter-flyway` + `org.flywaydb:flyway-database-postgresql` (runtime, Boot-managed — Spring Boot 4's
   Flyway starter needs this database-specific module alongside it, confirmed against Spring Boot's own docs this session;
   the MySQL-era plan's `flyway-core` + `flyway-mysql` naming no longer applies); `org.testcontainers:testcontainers-postgresql`
   2.0.5 beside the existing Testcontainers rows (`pom.xml:84` – `:96`), matching the pinned Testcontainers version already
   there (confirmed against Testcontainers' own published coordinates for 2.0.5 this session).
2. **Converters:** `shared/protection/EncryptedColumn` (text) and `SearchableColumn` (text, and a list of text) as JPA
   `AttributeConverter`s on the same `FieldCipher`, so stored ciphertext is byte-for-byte what MongoDB holds (C3a of D-928
   depends on it). Date and enum forms wait for a caller (W-337c).
3. **Flyway:** `V1__auth_and_insurance.sql`: `user_details` (unique `email`), `refresh_tokens` (unique `token_hash`, indexes on
   `family_id`, `email`, `expires_at`), `refresh_token_factors`, `insurances`, `insurance_policy_details` (child table);
   `TIMESTAMPTZ(6)` for times (not plain `TIMESTAMP`: every time is an already-UTC instant via `TLocalDateTime.atUtc()`, and
   `TIMESTAMPTZ` is Postgres' type for that, unlike MySQL's `DATETIME(6)`), `DOUBLE PRECISION` for `premium` (Postgres' name
   for MySQL's `DOUBLE`, same IEEE-754 double), `DATE` for the policy dates.
4. **Entities and repositories:** the three classes move from `@Document` to `@Entity`; repository interfaces to `JpaRepository`
   with their derived names unchanged; the `MongoTemplate` calls become `@Modifying` JPQL updates (the spend checks the row
   count is 1, keeping it atomic); `LoginIndexInitializer` deleted (Flyway owns the indexes).
5. **Tests first:** a PostgreSQL container (pinned to **18**, matching both Neon's and Aiven's `SELECT version()`) in
   `AbstractIntegrationTest` beside Mongo; new cases, each red before its change: a searchable email found by a derived query
   and stored as `FieldCipher`'s text; a spent token refused on a second spend in parallel; an expired row deleted at
   sign-in; `premium` `0.1 + 0.2`-style doubles and a `LocalDate` and an `Instant` read back equal; a ciphertext written by
   the Mongo converter read by the JPA one (the copier's premise).
6. **ADR:** `docs/modules/shared.md` or a short `docs/adr/W-337a.md` (C1 of D-928 closed or reopened, with what failed).
