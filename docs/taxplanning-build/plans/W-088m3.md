## Plan for W-088m3 — the guard: a node reaches rules only through rule sets

**What this item is for (one sentence):** a build rule that keeps W-088m1 and m2 from being undone. A node that names
a rule row in Java, instead of a rule set whose data chooses the row, fails the build (D-251).

### What I read (session 23, 2026-10-19)

- **`ArchitectureTest`** (`backend/src/test/java/com/thiru/wealthlens/architecture/ArchitectureTest.java`):
  - the engine's `@ArchTest` rules sit at `:162–291`;
  - the closest precedent is `nodes_ask_the_context_whether_a_rule_applies_in_the_regime` (`:248`), a `noClasses()`
    rule on `..taxengine.node..`;
  - the plain-`@Test` source scans (`:301`, `:352`) cover what bytecode cannot show.
- **Today's node package** (`taxengine/node`, 50 classes):
  - no `RuleIds` reference;
  - no `new RuleId(`;
  - no map whose values are `RuleSetId`. After W-088m2 the only `RuleSetId` collections are `Set<RuleSetId>`
    declarations.

  The baseline the WI row foresaw is therefore **empty**.
- **Outside the node package:**
  - `election/SetOffOrderElection.java:31, 42–43` and `election/HouseElection.java:35, 46–47` name `RuleIds` directly.
  - `Election.basis` (`election/Election.java:24`) returns a `RuleId`.
  - These are not nodes, and the WI row scopes the guard to `taxengine.node`.
- **The TS lists every build-enforced rule** in T10 (`02-TECH-SPEC.md:409–425`).

### Design

1. **One `@ArchTest` in `ArchitectureTest`:** `nodes_reach_rules_through_rule_sets`. No class in `..taxengine.node..`
   may:
   - depend on `rules.generated.RuleIds`; or
   - call the `RuleId(String)` constructor.

   The reason states D-251 / D-252: the row is the data's to choose, so a new regime's or a new item's row is reached
   with no Java change.
2. **(C3) A plain `@Test` source scan,** `nodes_hold_no_map_to_a_rule_set`. No `.java` file under `taxengine/node` may
   declare a `Map<…, RuleSetId>`, the item-keyed map W-088m2 removed. ArchUnit reads erased bytecode and cannot see a
   map's value type, so this is a source check like the `ComputationStep` gate.
3. **TS T10:** two rows, both ✅ `W-088m3`.
