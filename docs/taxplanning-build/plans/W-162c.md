## Plan for W-162c — the charge catalogue loses its deductibility flag

**What this item is for (one sentence, in my own words):** the last place the old law sits is the catalogue's
unversioned `deductible_for_capital_gains` flag, which is now read by nothing but its own seed gate and backfill; this
item removes the flag, the gate, the backfill and the JSON key, and the stored field from `charge_catalogue`, so the
catalogue keeps the charge's facts only and `RS-CG-CHARGE` is the one place the law lives (D-315 T4; D-375, D-377).

**Small: about 40 lines of main code removed, no code added, six tests removed, one test kept and renamed; one R15
runbook step.** This closes W-162 and the audit's T4.

### Choices (recommended first)

- **C1 — the stored `charge_catalogue.deductible_for_capital_gains`** (12 documents a database, seed data):
  - **(a) recommended:** an owner `mongosh` step, like §2.7:
    - **count:** `db.charge_catalogue.countDocuments({ deductible_for_capital_gains: { $exists: true } })`;
    - **backup:** `mongoexport` of `_id`, `code` and the field;
    - **unset:** `db.charge_catalogue.updateMany({ deductible_for_capital_gains: { $exists: true } }, { $unset: { deductible_for_capital_gains: "" } })`;
    - **check:** the count is 0.

    The match makes it idempotent: a second run, or one after a part-way run, matches what is left or nothing. There
    is no code to add or remove later. It is runbook §2.10, retired by Phase 15 row W-175 with a YouTrack child.
  - **(b)** a `SUPER_USER` endpoint like §2.9, with a dry run, the caller recorded and an integration test. That is
    about 100 lines added now and removed later, for a 12-row configuration collection the seeder itself writes
    without recording a caller per field.
  - **(c)** leave the field. It would be unmapped and harmless to the code, but a stale legal flag would remain in
    the database, which T4 exists to remove.
- **C2 — the seeder's "a stored code is never rewritten" case** (`seed_whenAStoredCodeAlreadyDeclaresDeductibility_leavesItAlone`):
  - **(a) recommended:** keep it as `seed_whenACodeIsAlreadyOnFile_neverRewritesIt`, without the flag. Skipping a
    stored code is behaviour that stays, and this is its only test.
  - **(b)** remove it with the rest.
