## Plan for W-045g2 — the provider serves packs compiled from the timeline (D-054)

**What this item is for (one sentence):** make the one pack loader build every year from the timeline
and refuse it unless it matches that year's lock, so the per-year copies can go.

### What I found (read this session)

1. **Six test roots use the per-year format** (`manifest.json` + layer files):
   - `rulepacks-fixture/2099-00` and `2098-99`: empty law. They test the provider's own contract, and
     2098 declares an all-zero law checksum.
   - `rulepacks-broken/2090`–`2093`: one defect each (checksum, I1, a dangling reference, the 400001 trap).
2. **One provider test passes for the wrong reason.** `aPackFiledUnderTheWrongYearIsRefused` loads
   2098-99, whose manifest *does* say 2098-99. It is refused for 2098's bad checksum, not for the year.
3. **T9-21 is not built as a test.** "The synthetic 2099-00 loads with no Java change" today means the
   fixture year loads through the provider. No test runs its pipelines.
4. **Beyond the row's list,** `PackJsonTest` (3 places) and `PackJsonWellFormedTest` (the whole class)
   read `rulepacks/2026-27/` directly. Removing that directory means reworking both, and
   `PackJsonTest`'s mutation tests use regexes that match today's file formatting, which compiled
   canonical JSON does not have.
5. The provider lives in `pack`, and `timeline` already imports `pack` (`RulePackLayer`,
   `RulePackRef`, `RuleRow`). A provider in `pack` that calls the compiler makes a **package cycle**.
   No ArchUnit rule forbids it (`grep` for cycle rules found none), but it is avoidable.

### A. Proposed split (§7): the row is again two items

- **W-045g2 (this):** the provider compiles from the timeline and checks the lock. The six test roots
  are migrated. `RulePackLoadTest` and `ClasspathRulePackProviderTest` are updated, including a real
  wrong-year case (finding 2). `NodeHarnessTest` and `PipelineRunnerTest` pass unchanged.
  **`rulepacks/2026-27/` stays** for now; nothing loads it, and `TimelineReaderTest`'s drift guard
  keeps it equal to the timeline.
- **W-045g3 (new):** remove `rulepacks/2026-27/`, and move everything that still reads it onto the
  timeline or the lock: `RuleIdNamingTest`, `ConstantGenerator`, `TimelineReaderTest`,
  `RulePackCompilerTest`'s two equality tests (retired), `PackJsonTest` and `PackJsonWellFormedTest`.
  That is the half with the most test rework (finding 4).

### B. Choices inside this item

- **B1 — no package cycle:** move `ClasspathRulePackProvider` (and its test) from `pack` to `timeline`,
  keeping the name. The `RulePackProvider` interface stays in `pack`. **Recommended.**
- **B2 — a timeline inside a JAR:** the provider resolves `<root>/timeline` through the class loader.
  A `file:` URL becomes a `Path`, and anything else is **refused with a message naming the unowned
  gap** (D-054). That is not a silent fallback, and not unowned work done early. **Recommended.**
- **B3 — broken roots:** one timeline per root, so each defect gets its own root,
  `rulepacks-broken/<defect>/{timeline/, <year>.lock.json}`: `checksum-mismatch` (2090, a lock with a
  zero law checksum), `unverified-without-what-to-check` (2091), `dangling-rate-table` (2092),
  `lower-bound-400001` (2093). Each timeline is the real one with exactly one defect.
  **Recommended.** Two defects (I1 and 400001) are now caught when the timeline is **read**, one step
  earlier than before, so their expected messages name the timeline file
  (`law/rules/RATE-SLAB-NEW-TAX-REGIME.json`) instead of `law/rates.json`. The defect is unchanged.
- **B4 — the fixture root:** git cannot hold an empty timeline, so it gets one synthetic node,
  `exec/pipelines/fixture.node.json`, plus these locks:
  - `2099-00.lock.json`, correct checksums, keeping version `2099-00.law.3`, which the test asserts;
  - `2098-99.lock.json`, a zero law checksum;
  - `2097-98.lock.json`, which declares `taxYear` `2099-00`: a real wrong-year case (finding 2).

  **Recommended.**
