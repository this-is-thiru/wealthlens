### Choices (recommended first)

**C1 — how each figure is worked.** (a) From the **Gazette pages** the rows cite, each copy fetched again and its
sha256 compared with the one the repo records; the rates quoted with their page into a new
`sources/2026-11-07-boundary-figures.md`; each figure written out as arithmetic there (slab tax by band → surcharge →
marginal relief → cess → s.288B/s.516 rounding), Python used only as a calculator on the line written. For each
crossover, the relief-stops point is solved by hand (as `DR 08` did for T1-N4 and T2-3) and compared with the engine's.
(b) Take the rates from the rule JSON: reads the pack, not the law — a pack typo would be copied into its own oracle.

**C2 — where the cases go.** (a) New files in `T2/` (surcharge) and `T1/` (the age step), ids continuing the series
(`T2-6` …, `T1-A1g`), `source` naming the working document and line; each entry removed from the awaiting file as its
case lands, so the file ends empty. (b) A separate directory: the coverage test already reads T1 and T2 only.

**C3 — when a hand figure and the engine disagree.** (a) **Stop** (R13): the case is written with the hand figure,
the failing test is reported with both numbers, and nothing in the engine or the case is adjusted until the owner
rules. (b) Investigate and fix the engine within this item: a law-code change hidden inside a test item.
