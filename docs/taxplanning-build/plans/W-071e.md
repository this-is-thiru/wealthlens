### Findings

1. **Table IV is for every employee**, not only a specified one: s.17(1)(e) / 1961 s.17(2)(viii) prescribe these as
   perquisites outright (contrast OQ-10's car).
2. **Loans need a figure no Rule states:** SBI's rate for the purpose on 1 April. It is data per year per loan
   purpose that the Bank publishes, not law — the taxpayer (employer) enters it. The loan is valued month by month on
   the month-end balance.
3. **The years differ in five figures** (loans ₹2,00,000 / twenty thousand; meals ₹200 / fifty; gifts ₹15,000 / five
   thousand; the movable-asset exclusions; the new-regime voucher bar in TY 2025-26 only). H-2 names this trap.
4. **The gift test is "below", not "up to":** at exactly the threshold the **whole** amount is a perquisite
   (`PERQ-GIFT-BOUNDARY-001`). The meal limit is "to the extent … does not exceed" — only the excess per meal is.
5. **Nine benefits, nine input shapes** — too much for one reviewable item, as W-071 was.
