**Two findings that change the question:**

1. **The 2025 Act names the default regime "New tax regime" (Q1, Q2).** D-035, brief §5.2 and the PRD
   glossary ("Never call it: new regime") assume "new" is informal and relative. In the 2025 Act it
   is the **statutory heading**. It is also the heading of a whole Part (Q1, Q5), which holds the
   company and co-operative regimes as well, so on its own it does not pick out s.202.
2. **The other regime has no name in either Act.** s.202(4) only says sub-section (1) does not apply
   once the option is exercised (Q4), and its rates sit under "Rates of income-tax" (Q6). **No
   name built only from quoted words describes it well.** Every option in A2 below has a defect,
   stated there.

**A3 — rule IDs** follow A1/A2: `RATE-SLAB-<concept>`. `RuleId` is `^[A-Z]{2,8}(-[A-Z0-9]{1,12}){1,5}$`.
⚠ The item's Verify regex `-(OLD|NEW)\b` **rejects** `RATE-SLAB-NEW-TAX-REGIME`, because it assumed
"new" is never the Act's word. Options:
- (a) `RATE-SLAB-NEW-TAX-REGIME`, and change the Verify regex to reject `-(OLD|NEW)` **except**
  in the statutory phrase `NEW-TAX-REGIME` ← recommended if A1 = (a)
- (b) `RATE-SLAB-NEWTAXREGIME` (one 12-character segment). It passes the regex only because the
  word is run together; the regex stays as it is

Opted-out slab rule: `RATE-SLAB-FIRST-SCHEDULE` (if A2 = b), or `RATE-SLAB-<your A2>`.

**A4 — the old-regime age bands** (rulebook `RATE-SLAB-OLD-2025-A/-B/-C`; only the under-60 ladder
is in the pack). Brief §5.2 says "versions per year and per age band". The pack's `_note` says "the
60+ and 80+ variants are separate rules". Versions are split by **validity** (dates), not by age,
so I read the pack as right and the brief as loose. Proposed mapping: A → the base rule;
B → `…-AGE-60-TO-79`; C → `…-AGE-80` (Q7's words; not "senior citizen", because s.2(100) includes
80+ — Q8). Your call.
