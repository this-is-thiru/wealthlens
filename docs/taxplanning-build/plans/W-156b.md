## Plan for W-156b — health insurance by rule data

**What this item is for (one sentence, in my own words):** `HealthInsuranceDeduction` decides in Java who belongs to
which of s.126's two buckets (by relationship), which kinds a bucket takes (a scheme never a parent's), and how each
payment kind is treated (cash, spreading, the limb it fills, whether it raises the senior limit, s.126(7)). This item
makes those rows' conditions (D-343 R3, R4; audit P6).

**This plan raises C1 – C4. C1 is a split: the whole item is over §7, so the build below is W-156b1 only. C4 changes
one test assertion and asks your approval for it.**
