## Plan for W-131d2 — the reconciliation read: a draft's confirmed certificates against its computation

> **Approved as recommended — C1a – C4a** (owner, session 105, 2026-11-18). Every path:line below was read this session at `9e311737`.

**What this item is for (one sentence, in my own words):** let a person ask for a draft, "do my confirmed Form No. 130s agree with
this computation?", and get W-130's lines and verdict, with W-129's notices. This runs behind the documents switch.

### What the code says

- `Reconciliation.reconcile(confirmed, assembly, layout, computed, law)` (`documents/reconcile/Reconciliation.java:42`) fills the
  report's `documentIds` with **attempt** ids (`:44`). `DocumentConfirmation` carries no document id.
- `EmployerAssembly.assemble(attempts, layout, law)` (`documents/assembly/EmployerAssembly.java:42`) reads each **parse
  attempt's** interpreted values, and decides "has Part C" from the rows **read** (`:67`). Reconciliation uses the rows
  **confirmed**. Reconciliation's employer errors come from the assembly's notices, for example "1(e) nil → PREVIOUS_SALARY_UNDECLARED". So a person
  who corrects 1(e) still gets that error. That breaks M4: "nothing is used until this exists".
- `TaxCalculator.certificate(year, code)` (`taxengine/api/TaxCalculator.java:347`) and `salaryCertificateLaw(year)` (`:460`) give
  the layout and the law.
- The draft's regime: `DraftForecastService.regimeOf` (`compute/DraftForecastService.java:55`) returns the election, or else the year's
  default. It is package-private.
- `DraftService.ownedDraft` (`workspace/DraftService.java:128`) refuses a draft that is another account's or is held (`:284` calls
  `taxProfileService.owned`).
- `DocumentSwitch.requireEnabled` (`documents/DocumentSwitch.java:17`) is package-private. The parse view records
  `ReadSubject.DOCUMENT` (`documents/DocumentService.java:98`).
- The draft endpoints sit in `DraftComputationController`, for example `GET /drafts/{draftId}/forecast` (`compute/controller/DraftComputationController.java:81`).
- The documents with `comparisons` in the packs: only `FORM_130.json`, with 7 comparisons.
- `DR 07` `07-architecture.md:433` still names `/tax-planning/user/{email}/context/{taxYear}/reconciliation`, which is stale.

### Choices for the owner (recommended first)

- **C1 — what the assembly and the report read:**
  - **(a)** Confirmed values, everywhere:
    - a record `ConfirmedCertificate(documentId, DocumentConfirmation)` in `documents.ingest`;
    - `EmployerAssembly.assemble(List<ConfirmedCertificate>, layout, law)` reads `acceptedFields`;
    - `Reconciliation.reconcile(List<ConfirmedCertificate>, …)` reports **document** ids.
  - (b) Keep both as built. A correction then doesn't reach the assembly, and `documentIds` holds attempt ids. Each gap gets a placed item.
- **C2 — which certificates:**
  - **(a)** The draft's profile-and-year documents whose year's layout has printed `comparisons` (data: only Form No. 130 today).
    For each one, the **latest confirmed** attempt is used. A newer reading the person has not confirmed does not displace it.
    Documents with no confirmation are left out and listed in the response.
  - (b) `DocumentType.FORM_130` named in code. This breaks D-728 C1a ("which form a year prescribes is law, not Java").
- **C3 — which computation:**
  - **(a)** A fresh one, under the draft's regime (election, else the year's default), stored nowhere, as `/forecast` does.
    The response states the regime and the revision. To do this, `regimeOf` becomes public.
  - (b) The latest stored computation of the draft. It can be stale or absent.
- **C4 — the edges:**
  - **(a)** Switch off → 503 (`DocumentSwitch` made public).
  - **(a)** No confirmed certificate → 400 "No certificate of this draft's tax year is confirmed yet". Today `reconcile` with none
    answers `MATCHED`, which is a verdict invented from nothing.
  - **(a)** One `ReadSubject.DOCUMENT` read is recorded per certificate used.
