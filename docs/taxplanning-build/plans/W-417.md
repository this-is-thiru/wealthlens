**Hand-worked values for the tests:**
- `2023-09-21T18:30:00Z` read at UTC → **2023-09-21** (what `m1.6.1` shows); the same instant is 2023-09-22 00:00 in Asia/Kolkata,
  which is why it counts as "midnight in the written zone".
- `2023-09-21T00:00:00Z` → 2023-09-21, not counted (the usual form).
- `2023-09-21T12:00:00Z` → refused (midnight in neither zone), as today.
- With written zone UTC, `2023-09-21T18:30:00Z` → refused: only the written zone's midnight is accepted.
