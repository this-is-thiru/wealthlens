### The rule, stated once

The vehicle's path row (`RS-PERQ-CAR-PATH`) names its computation. Then:

- **who meets the private running**, when entered as true, is refused unless flipping it changes the path the vehicle
  reaches. This is the flip test of `EntryFacts.arrearsReliefIsRead`. The path rows partition the vehicles, so a fact
  is read exactly where its value routes them;
- **a chauffeur, a cost, a charge and a higher official use** are refused when the computation does not read them
  (the table above). The cost is required where it does: `whollyPrivate`'s existing refusal stays.

Refusals name the vehicle, the fact and the path row: "Vehicle 1: PERQ-CAR-PATH-PRIVATE does not read a chauffeur;
it would be ignored, so it is refused".
