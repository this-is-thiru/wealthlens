### Findings

1. **Nothing in main code changes.** The engine already computes T2: `SurchargeNodeTest` reproduced every
   T2 surcharge at node level. W-057 adds the end-to-end proof, from total income to rounded payable,
   with U priced by real re-entry rather than a stub.
2. **DR 08 states three assertions besides the figures**, and they're copied too:
   - T2-3: the relief and no-relief branches "must **meet continuously** at the crossover" — both
     incomes pay the same;
   - T2-4: "**THERE IS NO 37% BAND**" in the new regime — the surcharge line cites the 25% ladder;
   - T2-5: "exactly ₹10 above T2-4's old-regime figure".
3. **The case ids.** DR 08 gives T2-3 and T2-4 two figures each: two incomes, and two regimes. Following
   T1's `A1a`…`A1f`, they become **T2-3a / T2-3b** (₹51,61,190 / ₹51,61,200) and **T2-4a / T2-4b** (old /
   new, in DR 08's order). Each file quotes its DR 08 line.
4. **Ages.** T2-4 and T2-5 use `RATE-SLAB-OLD-2026-A` (below 60). That's the runner's default taxpayer,
   so no `ageAtYearEnd` is needed, as in T1-O1 … O3.
5. **Standing rules (D-043):** none apply. There are no rules, sections or concept IDs. Both years run
   every case, as DR 08 says.
