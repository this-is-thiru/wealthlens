## Plan for W-156e — salary kinds by rule data

**What this item is for (one sentence, in my own words):** five salary choices are tests on an input's kind in Java:
which employer contributions are the RPF contribution charged above 12% (`EmployerContributionNode:140`), which are
the pension-scheme contribution that is salary (`GrossSalaryNode:93`), which employments' entertainment allowance is
deductible (`SalaryDeductionNode:177`), which allowances are per child (`AllowanceExemption:57`, `:162`), and which
journey mode takes the per-kilometre rate (`LeaveTravelExemption:211`). This item makes each a row's condition or
shape (D-343 R7).

**This plan raises C1 – C3. No test assertion changes.**
