### Findings

1. **Only T4's salary-side figure for the aggregate is buildable now.** ₹74,000 in T4-1 and T4-2, and
   `PF-AGGCAP-001`'s nil in T4-3, come from built code. Everything else is owed by unbuilt items: the deductions

   figure the code does not produce) for want of code, not for a wrong number.
2. **T4 states no accretion facts, and D-127 refuses an excess without them.** DR 08 predates the s.17(1)(i)
   accretion being built; as written, T4-1 and T4-2 are refused, not ₹74,000.
3. **Whether the employer's NPS contribution is itself salary is not settled in the design.** T4-2 says the
   uncapped ₹96,000 "remains income", which assumes the ₹3,36,000 is in income before the deduction; `DR 01` R13
   says only that it is counted in the aggregate and deducted. No component or rule in the pack makes it salary.
   I have not read the provision that would (and will not state one from memory) — it bears on `W-076`, not on
   the figures this plan asserts, so it is raised as **OQ-14**, not resolved here.
4. **T4-4's premise is out of date.** It expects an `UNVERIFIED_RULE` notice because r.9D was unread; sourcing
   round 4 read r.9D (X2) and r.277. That is `W-079`'s to settle, with an erratum then.
5. **TY 2025-26 runs will be PROVISIONAL**, though DR 08 does not mark T4-1/T4-2 ⓟ:
   `PERQ-EMPLOYER-CONTRIBUTION`'s TY 2025-26 version is `UNVERIFIED` (interim FA 2024 unread; D-126 C5).
