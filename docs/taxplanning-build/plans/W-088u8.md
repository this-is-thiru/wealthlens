## Revision 1 — idempotency and removal (owner, D-282)

- **W-088u8b's C2a changes, from "refused unless the collection is empty" to per user.** The rebuild writes only for
  users who have **no** `trade_outcomes` rows, of any writer, and skips and reports the rest.
  - Why: a run that failed after some users would otherwise leave the collection non-empty, and every re-run would
    then be refused. The rebuild would be stuck half-done.
  - The result: a re-run completes it, and a run on a fully built collection writes nothing.
  - V1 and V2 rows are still never duplicated: a user with any row is skipped.
- **Every one-time operation built here is removed after use** (owner):
  - W-088u8a's seed endpoint → **W-088u9b**; W-088u8b's rebuild endpoint → **W-088u9c**; W-088u7's correction
    endpoint → **W-088u9a**;
  - W-088u8c already removes the two finished runners.
  - Parent **W-088u9**; YouTrack WL-28 – WL-33.
