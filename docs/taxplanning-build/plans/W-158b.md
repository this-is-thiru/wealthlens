### The rule, stated once

The accommodation's `RS-PERQ-ACCOM` row reaches it by provider. Then:

- a **population** must be entered when that row's cap counts `POPULATION`, and is refused when it does not;
- an **employer's cost** must be entered when the cap reads `EMPLOYER_COST`, and is refused when it does not;
- a **first year's amount** is refused unless a `RS-PERQ-ACCOM-CONTINUED` row reaches the accommodation **and** it is
  continued. Where both hold, `continuedCap` already requires it;
- **furniture** is refused unless a `RS-PERQ-ACCOM-FURNITURE` row reaches the accommodation.

A refusal names the row (or the set, where none reaches) and the fact, as `EntryFacts` does. For example: "EMPLOYER_LEASED
is not measured on a population (PERQ-ACCOM-LEASED); it would be ignored, so it is refused".
