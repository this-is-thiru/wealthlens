### Choices (recommended first)

- **C1 — the definition's vocabulary:**
  - **(a) recommended:** an enum `VehicleComputation`, named after the arithmetic, not the Table's serial numbers.
    Each value says which valuing set it reads:

    | Value | Computation | Valuing set |
    |---|---|---|
    | `NOT_A_PERQUISITE` | nil | — |
    | `PER_MONTH_EMPLOYER_RUNNING` | the column's monthly amount × months, plus the chauffeur's | `RS-PERQ-CAR-PARTLY` |
    | `PER_MONTH_EMPLOYEE_RUNNING` | likewise | `RS-PERQ-CAR-OWNRUN` |
    | `RUNNING_AND_WEAR_LESS_CHARGE` | running + wear and tear on the cost for the months − the charge | `RS-PERQ-CAR-PRIVATE` |
    | `OWN_CAR_EXPENDITURE_LESS_TABLE_AMOUNT` | the expenditure less Sl. 1(c)(i)'s amount for the engine (V4), or a higher claim | `RS-PERQ-CAR-EMPLOYEE` |
    | `OWN_CONVEYANCE_EXPENDITURE` | the expenditure less the row's monthly sum, or a higher claim | `RS-PERQ-CAR-CONVEYANCE` |

    The definition is a record `VehiclePath(VehicleComputation computation)` in `rules/definition`, one permit, and
    `DefinitionJson` reads it with `PackJson.enumValue`.
    - It is closed (an enum). A new computation is new arithmetic, so new code anyway. A Table that renumbers or
      re-reaches its serials is new conditions on the path rows.
    - `CapitalGainsPart` is open only because its parts are declared data with no per-part code.
  - **(b)** the Table's serials (`SL_1C_I`, `SL_2B`, …). These lie when a year renumbers.
- **C2 — the several-cars proviso until W-154e3 (V5):**
  - **(a) recommended: interim, as W-153c1 C2a.** `employerCar` keeps the proviso for an employer's car whose path
    is one of the three employer computations. Where more than one of the employment's cars is shared, the first is
    valued at `PER_MONTH_EMPLOYER_RUNNING` and the rest at `RUNNING_AND_WEAR_LESS_CHARGE`, whatever their own path
    says, as today (`:87–91`). W-154e3 replaces it with conditions.
  - **(b)** do W-154e3 first. The proviso's conditions need the path rows to exist, so the interim is the same, the
    other way round.
