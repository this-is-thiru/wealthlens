**Findings that shape the build:**
1. Every stored key matches its field by D-977's rule (its snake_case Java name) **except three**, whose `m1.6.1` `@Field` names
   differ and are gone from the classes: `FinancialReport.monthlyReport` ← `capital_gains`, `MonthlyReport.firstFortnightReport` ←
   `first_half_report`, `.secondFortnightReport` ← `second_half_report` (W-337g's finding, `plans/W-337g.md` line 34).
2. Map keys are enum names (`EQUITY`, `DELIVERY`, `JANUARY`); the walk will check each against its enum, as it does values.
3. Times, each from its `m1.6.1` setter:
   - `RealisedProfits.lastUpdatedTime` = `LocalDateTime.now()` (`ProfitAndLossService.java:131, 420`) — **local-held**.
   - `ChargeSummaryReport.lastUpdatedTime` = `TLocalDateTime.now()` in `merge` (`ChargeSummaryReport.java:71`), which was
     `ZonedDateTime.now(UTC).toLocalDateTime()` (`TLocalDateTime.java:16-18`) — **UTC-held**.
   - `ReportModel.lastUpdatedTime` carried only `@LastModifiedDate` and no code set it; `m1.6.1`'s own `ChargeSummaryReport`
     Javadoc (lines 23 – 26) says auditing never fires for a nested object, "so the annotation alone would leave the field
     permanently null". So every stored `ReportModel` time is null — see C2.

### Decisions (for approval)

- **C1 — the three renamed keys.** **C1a (recommended):** a small table in the copier, `FormerFieldNames`, from (class, field) to
  the `@Field` name `m1.6.1` stored it under, each entry citing that line; `JsonWalk` checks it before D-977's rule. Three entries.
  **C1b:** put the `@Field` annotations back on the classes — MongoDB annotations on classes that no longer live in MongoDB, removed
  again by W-337j; not recommended.
- **C3 — `CopierRun`'s refusal once nothing is unspecified.** `CopierRun.run` reads `CollectionCopies.unspecified()` itself, so with
  every collection specified `CopierRunTest`'s refusal case (`CopierRunTest.java:31-37`) has nothing to refuse, and deleting it would
  drop the guard that stops a future `m1.6.1`-unknown collection being copied around. **C3a (recommended):** move the check into a
  package-private `CopierRun.requireSpecified(Set<String> unspecified)`, called by `run` with `CollectionCopies.unspecified()`; the test
  calls it with `{"profit_and_loss"}` and keeps its message assertion. `run` actually running is W-337g2c's case (its row). **C3b:** leave
  `CopierRun` alone and move the refusal case to W-337g2c — a guard untested between two commits; not recommended.
- **C2 — `ReportModel.lastUpdatedTime`.** **C2a (recommended):** no `EmbeddedTimes` entry: the field was never set at `m1.6.1`, so a
  stored value is unexplained and is refused (the rehearsal, W-337i, would show one), never guessed. **C2b:** classify it local-held,
  as auditing would have stamped it — a guess about data that should not exist; not recommended.
