and let a column declare printed captions, so Form 16's Part A boxes (p.28) can be put in the pack as four one-row
tables (D-745 C1a, C2a, C4a). Reading them is W-126e3b.

   totalLabel` (`CertificateLayout.java:92` – `:103`).
2. **Compile reach.**
