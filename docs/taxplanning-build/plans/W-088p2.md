### Design

1. **`DonationDeduction`: a private `Group(RuleSetId set, String what)`.** It has four constants, `WHOLE`,
   `WHOLE_LIMITED`, `HALF` and `HALF_LIMITED`, holding today's texts word for word. The call becomes
   `deduct(ctx, group, counted, firstSequence, lines)` (5 parameters), and the row is `ctx.ruleIdOf(group.set())`.
2. **`ExemptionNode.period(ctx, tenancy, allowanceForYear, salaryForYear, sequence)`** (5 parameters). The row is
   `ctx.ruleOf(RS_SAL_HOUSE_RENT_ALLOWANCE)` and the temporal context is `ctx.inputs().temporal()`. Its two lines use
   `ctx.traceLine(...)`, which gives the same node and the same governing-version provenance (W-088p1).
3. **`OtherSourcesNode`: `InFullRow` becomes `KindRow`.** Its fields stay `ruleSet, base, what`, but it now also
   describes the whole-deducted kinds. A `WHOLE_DEDUCTED` map holds `COMMUTED_FUND_PENSION` and `DEATH_GRATUITY` with
   today's sets, bases and texts. `wholeDeducted(lines, where, item)` (3 parameters) reads the map, as `inFull`
   already does.
4. **`RetirementNode.payment(ctx, components, payment, allowedThisYear, sequence)`** (5 parameters). It works out
   `gratuityReceived` itself, in the commutation branch, keeping D-226's comment with it.
   **`voluntaryRetirement(ctx, ruleId, received, allowedThisYear, sequence)`** (5 parameters) takes the row and the
   temporal context from the node's context.
5. **`ElectionResolver`: a private `Combination(RegimeSpec regime, EngineInputs inputs)`**, the regime and inputs one
   combination of choices names. `combination(all, picks, regime, inputs)` (4 parameters) folds the choices, and
   `resolveTogether` calls `PipelineRunner.run(registry, pack, chosen.regime(), chosen.inputs())`. `runChoosing` is
   removed.

### Choices (recommended first)

- **C1: `RetirementNode.line` (5 parameters, W-088p1's shape, 6 calls):**
  - **(a) recommended:** delete it and use `ctx.traceLine(...)`. `voluntaryRetirement` and `payment` then need no
    version for the line. The traces stay identical, and W-088p1's tests guard the node and the provenance.
  - **(b)** keep it, and `voluntaryRetirement` works out the version again only to pass it on. A row would be placed
    for it.
- **C2: `ExemptionNode`'s other inline HRA line** (the not-in-regime branch, `:155`, `TraceLine.of` under
  `SALARY_EXEMPTIONS` with the version's provenance):
  - **(a) recommended:** use `ctx.traceLine(...)` there too, so the node's HRA lines are built one way.
  - **(b)** leave it.
- **C3: the resolver's type:**
  - **(a) recommended:** `Combination(regime, inputs)`. It names what the fold produces, and the public signatures
    are untouched.
  - **(b)** a record of all four run arguments (`registry, pack, regime, inputs`). That type would mirror
    `PipelineRunner.run`'s list for one private caller.
