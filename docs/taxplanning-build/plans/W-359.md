**What this rebuild is for (one sentence, in my own words):** give the API one standard error shape, standard token handling with
refresh, and URLs that say who may call them and which module answers — so no route can skip the security rules and the API is
documented from the code.

### Decisions (for approval with this plan)

- **C1 — one response shape.** **C1a (recommended):** drop the `{"data": …}` wrapper everywhere — plain JSON bodies, errors as RFC 9457
  `ProblemDetail` (`application/problem+json`: `type`, `title`, `status`, `detail`, field errors) — so tests and production return the
  same thing. Breaking for anything reading `.data`: the api-collection and your own `jq '.data…'` commands (rewritten here). **C1b:** keep
  the wrapper and switch it on in tests too (68 test files change; the wrapper stays a non-standard shape).
- **C2 — old URLs.** **C2a (recommended):** cut over in one commit — the only callers are the api-collection and you, and the app runs
  only on your machine. **C2b:** serve old and new paths side by side for a release, then remove the old.
- **C3 — tokens.** **C3a (recommended):** Spring's resource server (`oauth2ResourceServer` with its JWT encoder / decoder), HS256 with the
  **existing** `JWT_SECURITY_KEY` (no new key to create or deploy); access token **15 minutes**, refresh token **14 days**, rotated on each
  use, stored hashed, revoked on logout, password change, hold and erasure; a key id in each token for later rotation. **C3b:** asymmetric
  keys (RS256 / EdDSA) — a new key pair per environment to create and store; only worth it when something else must verify tokens.
- **C4 — URL shape.** **C4a (recommended):** `/api/v1/{public|me|admin}/{module}/{resource}`, the prefix added by Spring from a zone
  annotation and the controller's package; module names from a short table (`brokercharges` → `charges`, `taxplanning` → `tax`,
  `corporate` → `corporate-actions`, `shared`'s privacy routes → `privacy`, `helper` → `templates`); `/me` takes the user from the token,
  admin routes name the user explicitly. **C4b:** module but no zone (`/api/v1/{module}/…`) with per-route rules.
- **C5 — Swagger UI.** **C5a (recommended):** the OpenAPI spec and Swagger UI in the **admin** zone (a `SUPER_USER` token), on in every
  profile. **C5b:** off in prod.

### The four commits, in order

**1 — W-359a: one response shape (`ProblemDetail`), Actuator.**
- `ResponseWrapperAdvice` and `ApiResponse` removed (C1a); `ControllerAdviser` answers `ProblemDetail` with the same status codes and
  messages as today (W-263's mapping kept); `ErrorResponse` removed.
- Actuator `health` and `readiness` exposed, everything else of Actuator off.
- Tests: unchanged where they read bodies (they already read unwrapped); error assertions move to `ProblemDetail` fields (red first: a
  test asserting the problem shape fails on today's code). `RouteAccessIntegrationTest` keeps passing.

**2 — W-358b: Spring's token handling and refresh tokens (C3a).**
- `oauth2ResourceServer().jwt()` replaces `AuthFilter`, `jjwt` and `CustomAuthenticationProvider`; login through Spring's
  `AuthenticationManager` (`DaoAuthenticationProvider`, already configured in `AuthConfig`); authorities from the token's claims;
  held accounts still refused at once (a token check against `HeldAccounts`).
- `POST …/token/refresh` (rotating), logout revokes; a `refresh_tokens` collection (hashed, expiry, family) with its indexes.
- `UserValidator` stays until commit 3 replaces it.
- Tests: the harness's `generateToken` signs with Spring's encoder; new tests for refresh rotation, reuse detection, revocation on
  logout / password change / hold. Red first for each.

**3 — W-358c: zoned, module-scoped URLs, `/me`, DTO-only, REST routes, pagination (C2a, C4a).**
- `@PublicApi` / `@MeApi` / `@AdminApi` on every controller; the prefix added by `PathMatchConfigurer.addPathPrefix`; the module table;
  `/me` routes take the user from the token (no `{email}`); `UserValidator` removed.
- `AuthConfig` rules per zone and `anyRequest().denyAll()`.
- No controller returns a `@Document` (DTOs, e.g. `PortfolioController.java:98-99`); REST nouns and verbs; pagination on list routes.
- Guards: an ArchUnit rule (every controller has exactly one zone annotation; none declares its own `/api` prefix; none returns an
  entity); `RouteAccessIntegrationTest` rewritten for zones (no token → 401 outside public; `/me` only ever returns the caller's data;
  admin needs `SUPER_USER`).
- The 68 test files' paths updated; the api-collection's 142 requests rewritten (the submodule's pointer staged in this commit).

**4 — W-359b: the API documented from the code (C5a).**
- springdoc OpenAPI generated from the controllers and DTOs, served with Swagger UI in the admin zone.
- A build check that every api-collection request matches an operation in the spec (method, path, body fields).
