- **`OtherSourcesNode.reaches(ctx, RuleId row, OtherSourceItem item)`:**

  - tests them against `ctx.conditions().about(factsOf(item))` with `allMatch`.
- **`RowReach.holdsFor(ctx, RuleRow row, ItemFacts item)`:** the same three steps, but it takes the row itself.
  `ctx.rule(row)` also checks that the node declared a set holding the row; `holdsFor`'s callers pass rows they took
  from their own sets.

  `DividendInterestAllowance` (1), and `SurchargeNodeTest:532` (1). All pass a `RuleId` and an `OtherSourceItem`.
