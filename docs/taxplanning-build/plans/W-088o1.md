## Plan for W-088o1 — the capital-gains parts declared as rule data

**What this item is for (one sentence, in my own words):** the s.108(2)(b) rule — a long-term loss may be set off
only against long-term parts — and each part's term move out of the `CapitalGainsPart.isLongTerm()` switch into a
tax-year-versioned row, `CG-PARTS`, that both set-offs read (D-309 C1a, C2a). The enum itself stays until W-088o2.

**This plan raises C1 – C2.**

### Choices (recommended first)

- **C1 — the trace:**
  - **(a) recommended:** set-off lines unchanged, word for word. They cite `SETOFF-WITHIN-CAPITAL-GAINS` /
    `SETOFF-CARRIED-CAPITAL-GAINS`, whose notes quote the restriction; `CG-PARTS` is a declared set the receipt's rule
    list carries (both nodes declare `RS-CG-PARTS`). Every existing trace assertion stands as proof nothing moved.
  - **(b)** each long-term set-off line adds *"; parts a long-term loss reaches as declared by CG-PARTS"*. More
    traceable, but every long-term set-off assertion changes.
- **C2 — a part the declaration leaves out, or names twice, or a term code other than `SHORT_TERM` / `LONG_TERM`:**
  - **(a) recommended:** the definition refuses a part named twice and a blank term (`IllegalArgumentException`, at
    pack load). The node refuses, naming `CG-PARTS`, a part with a gain or loss that the declaration omits, and a term
    code it does not know — the rules package cannot see `Term`, and while the enum is closed, `CapitalGainsHead`
    still holds every constant. W-088o2 moves "every part declared" into `PackValidator`.
  - **(b)** the definition requires every enum constant (`EnumSet.allOf`, as `CapitalGainsAbsorptionOrder` does).
    Simpler now, but it is the very closed-set check W-088o2 deletes.

### The build (C1(a), C2(a))

1. **Definition** `rules/definition/CapitalGainsParts(List<Declared> parts)` with
   `record Declared(CapitalGainsPart part, String term, boolean canAbsorbLongTermLoss)`. Javadoc: the parts of the
   head, their term (the gains each collects, as `RS-CG-PART` tests it) and whether a long-term loss may be set off
   against each (S2 s.108(2)(b), s.111(1)(a)(ii); 1961 s.70(3), s.74(1)) — data, so a new part or a changed
   restriction is a row. Defensive copy; null, empty, duplicate part, blank term refused. One lookup,
   `Optional<Declared> of(CapitalGainsPart)`. Added to `RuleDefinition`'s permits; `DefinitionJson` reads
   `{"type": "CapitalGainsParts", "parts": [{"part": "…", "term": "…", "canAbsorbLongTermLoss": …}]}`.
2. **Rule set `RS-CG-PARTS`** (`EXACTLY_ONE`, `REGIME`) in `rule-sets.json`, `_note` "One row: CG-PARTS".
   **Row `CG-PARTS`**, two versions, `AllRegimes`, no conditions:

   | Part | term | canAbsorbLongTermLoss |
   |---|---|---|
   | `SHORT_TERM_SLAB` | `SHORT_TERM` | false |
   | `SHORT_TERM_LISTED_EQUITY` | `SHORT_TERM` | false |
   | `LONG_TERM_OTHER` | `LONG_TERM` | true |
   | `LONG_TERM_LISTED_EQUITY` | `LONG_TERM` | true |

   (today's `isLongTerm()`, both columns; the enum's order). Provisions, `introducedBy` and `provenance` per version
   copied from `SETOFF-WITHIN-CAPITAL-GAINS` (1961 s.70(2), (3); 2025 s.108(2)); the `_note` quotes s.108(2)(b) and
   s.111(1)(a)(ii) from the two set-off rows' notes, says the carried restriction's own row is
   `SETOFF-CARRIED-CAPITAL-GAINS`, and that which bucket falls in which part is `RS-CG-PART`'s. `SOURCE_CHECKED`, as
   the rows copied are.
3. **`CapitalGainsNode`:** declares `RS-CG-PARTS`; reads the declaration once in `evaluate`; a part's loss is
   long-term iff its declared term is `Term.LONG_TERM.name()`; the long-term `reaches` is `canAbsorbLongTermLoss`.
   The refusals of C2(a). Methods ≤ 60 lines.
4. **`SetOffNode`:** declares `RS-CG-PARTS`; `carriedCapitalLosses` takes the declaration (with `order`; 4
   parameters) and the long-term `Portion` reaches `canAbsorbLongTermLoss` parts.
5. **`CapitalGainsPart`:** `isLongTerm()` deleted; Javadoc says the term and the restriction are `CG-PARTS`'s.
6. **Coverage:** `CG-PARTS` beside `SETOFF-WITHIN-CAPITAL-GAINS` wherever the register lists it, and beside
   `SETOFF-CARRIED-CAPITAL-GAINS` (2025 s.111, 1961 s.74).
7. **Regenerate** `RuleIds` / `RuleSetIds`; **relock**, one bump: law 2025-26.84 → .85, 2026-27.88 → .89; one row
   added each.
