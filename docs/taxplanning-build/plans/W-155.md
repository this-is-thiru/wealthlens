## Plan for W-155 — retirement paths by rule data (split proposal)

**What this item is for (one sentence, in my own words):** which computation a retirement payment takes, which bars
and limits reach it, and which facts it must carry are today decided in `RetirementNode`, `NotifiedRetirementLimits`
and `RetirementPayment` by tests on the payment's `RetirementEntry`. This item makes them rows or the rows' own
shapes, so a law that moves a bar or a limit to another entry is new data (D-313 P5; N1).

**This item is over §7. This plan proposes a split (C1) and builds nothing.** On approval I place the rows, record
the split (D-336) and write the first sub-plan, then stop.
