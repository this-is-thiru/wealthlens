### The rule, stated once

For each optional fact the input carries (a `true` boolean, or a value present), there must be a row in the node's
sets that mentions the fact (`Condition.itemFactsRead`) and whose other item conditions, those reading none of the
optional facts, hold for the item. Otherwise the fact is refused: "no row of RS-… reads F for this item in TY …; it
would be ignored, so it is refused".
