**What this item is for (one sentence, in my own words):** for each claim a draft's computation makes, list every
document the claim catalogue says it rests on, whether the draft shows it is held, and — where it is not — what closes
it and whom to ask for it (PRD F25; `DR 12` C3.2, `DR 22` C7).

**Probe (2026-11-16):**

  `evidence` (name and `closedBy`) and `askWhom` (`ClaimActor` and `askFor`). It does not say whether anything is held,
  and it does not say which request gets which document (`ClaimEvidence.java`; `ClaimRequest.java`). The integrity panel (W-119c,
  `:93`) gives rupee gaps per rule from `EvidenceHeld`. It says whether the landlords' particulars are on file only

**Choices for the owner:**

    It also runs the standing computation once, for its notices.

- **C2: how an evidence item names what answers it.**
  - **C2a (recommended):** catalogue data. Each `ClaimEvidence` gains `from`, the `ClaimActor` who provides it; it
    must be `YOU` or an actor in the entry's `askWhom`, and the compiler refuses otherwise (new check). It also gains

    its store in one exhaustive switch over product vocabulary, never over rule ids. A rule added later gets its item

- **C3: r.205(2) Sl. 3.**
