## Plan for W-167 — `TJsonMapper` without a silent `null`

**What this item is for (one sentence, in my own words):** `TJsonMapper` should never answer `null` for "there was
nothing to read". Missing input becomes a loud failure, so a caller cannot carry a `null` onward by accident
(CLAUDE.md §2, "Nothing silent").

**Source:** `03-WORK-ITEMS.md` W-167; `reviews/2026-10-21-law-in-code-audit.md` § W-088l3, row **T7** (N7, from
`plans/W-088r.md:122`); D-315.

### What I read (session 38, 2026-10-28)

`shared/util/collection/TJsonMapper.java` has five `return null` lines. Each is listed below with its callers
(`grep` over `src/main` and `src/test`):

| Line | Method | Callers | What the `null` does today |
|---|---|---|---|
| `:31` | `safeReadAsList(String, Class)` (public) | **none** | — the method is dead |
| `:38` | private `readAsList(mapper, String, Class)` | via public `readAsList(String, Class)`: **tests only** (`TJsonMapperTest:18`, `:25`; `PortfolioIntegrationTest:730`) | an empty string answers `null` |
| `:46` | private `readValue(mapper, String, Class)` | via `copy` (12 main sites) and `safeCopy` (`ProfitAndLossService:247`) | **never reached**: its content is always `writeValueAsString(source)`, which is never empty. A `null` *source* serialises to `"null"`, and Jackson then reads that back as `null`. That is the real silent path, one line earlier. |
| `:66` | `readAsList(Object, Class)` (public) | `AuthHelper.getAuthorities:48`, reading the JWT's roles claim | a token with no roles claim → `null` → `roles.stream()` NPEs (`:49`) |
| `:83` | `readValue(String, Class)` (public) | **none** | — its Javadoc names "the tax rule-pack loader", which no longer calls it |

- **`AuthFilter`** (`auth/filter/AuthFilter.java:36-67`) wraps `getAuthorities` in a `catch (Exception)`, which is
  suppressed in `checkstyle-suppressions.xml:18`. Any failure there, today's NPE or a thrown refusal, logs and
  continues **unauthenticated**. The request then meets the security chain's refusal. So for the one live null
  path, a loud failure changes no response.
- **Every `copy` call site** passes a non-null value: list elements, `getFirst()`, a built context. No caller
  handles a `null` result.
- **Jackson 3 already throws** on empty content (`MismatchedInputException`), and on a `null` content argument.
  Removing the guards turns them into failures without any new code.

### Choices (recommended first)

- **C1 — what replaces each `null`:**
  - **(a) recommended: a thrown failure, and delete the dead methods.** No caller wants "absent" from this class.
    - `safeReadAsList` (`:31`) and `readValue(String, Class)` (`:83`) have no callers. Deleting them follows §2's
      "no dead weight". The orphaned private `readAsList(mapper, …)` overload is folded into its one remaining
      caller.
    - `:38`, `:46`: the guard goes, so Jackson's own exception reports empty content.
    - `:66`, and `copy` / `safeCopy`: `Objects.requireNonNull(source, …)` with a message naming what was absent.
      That is an NPE, so a 500, because it is a programming error and not a client's bad request. An
      `IllegalArgumentException` would map to 400 (`ControllerAdviser`).
  - **(b) `Optional`.** `readAsList(Object)` returns `Optional<List<T>>` and `AuthHelper` decides. That suits an
    optional input, but a missing roles claim is not optional: the app always writes it (`AuthService:138`).
- **C2 — `AuthHelper.getAuthorities` on a token with no roles claim:**
  - **(a) recommended: it fails loudly** with the C1a refusal, which `AuthFilter` already turns into
    "unauthenticated". No response changes. The log now says what was missing instead of an NPE.
  - **(b)** It answers no authorities (an empty list), so the user is authenticated with no roles. That is a
    behaviour change in authentication, and not one this item should make.
