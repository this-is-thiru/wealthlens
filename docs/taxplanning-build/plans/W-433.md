### The rules every sub-item applies
- **Delete** a comment that restates its code (the name, the signature, the next line), and history: what the code was before,
  which item changed it, a store or design that is gone — unless that history is the reason a constraint still stands, which is
  then stated in present terms (W-431's rule).
- **Keep** the reason a design is the way it is; a public type's contract; an ordering, bound, race or invariant the code does
  not show; a legal or source citation (`sources/…`, a section of the Act or Rules); a test named as the proof.
- **No code change.** Only comment lines move; the diff check of W-431 (every changed line a comment) proves it.
