### Choices (recommended first)

**C1 — test shape.** **(a) Recommended:** W-240a's shape, one parameterised refusal method per record over
`InputRefusals.refusal` cases, with one bad field per case. For **`EnteredFacts`** and **`LedgerSnapshot`**, one
reflective case source, `InputRefusals.eachComponentNulled(valid, prefix)`. It takes the valid instance
(`EnteredFacts.none()`, `LedgerSnapshot.empty()`), reads every non-primitive component, rebuilds the record through
its canonical constructor with that one component `null`, and expects `"<prefix>.<component> may not be null"`. That
covers each null check from the contract, so a component added later is checked with no new line. (b) Hand-write
about 40 constructions of the 34-argument record.

**C2 — the gate.** **(a) Recommended:** `check-taxengine`'s branch minimum goes 0.86 → **0.90**, X5.5's figure, if
the measured figure reaches it. If it lands between 0.89 and 0.90, I stop and report rather than set a floor below
X5.5, because this item's end point is 90 %.

**C3 — size.** **(a) Recommended:** one item. I estimate about 450 lines of tests, which is over §7's 300, but they
are table-shaped like W-240a's (approved at a similar size), and the item's end point is one gate step. (b) Split
into W-240b1 (`CapitalGainsInput`, `FairMarketValueBasis`, `HouseProperty`, the eight-miss files, `EnteredFacts`,
`LedgerSnapshot`: 81) and W-240b2 (the rest: 66), with 0.90 set by W-240b2.

### Five roles

- **Architect:** test code and one build number. The reflective case relies only on the records' public canonical
  constructors.
- **Product manager:** no user-visible change. The refusals a client can reach through a draft patch
  (`EnteredFacts`, `LedgerSnapshot` and their parts) are now proven.
- **Senior engineer:** one shared case helper, and no per-component boilerplate for the two large records.
- **Automation tester:** messages are read from the contract, there are three probes, and the gate is checked
  against the real coverage data, not only by the build.
- **Manual tester:** nothing to run by hand. `backend/target/site/jacoco/index.html` shows `taxengine.input`.

**Risks or ambiguities I noticed:**

  null, the reflective case fails. I would then report it rather than exempt it, since CLAUDE.md §2 forbids a null
  crossing a boundary.
