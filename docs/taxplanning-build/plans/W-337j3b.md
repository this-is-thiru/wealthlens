### Choices

- **C1 — how the read-only SQL is proven.** **C1a (recommended):** I write every read-only query of the 14 sections into one
  `psql` heredoc (one `\echo` label per query); you run it once on dev with the `PSQL()` wrapper (dev's values) and paste the
  output; a query on a table dev holds no rows of is also run on staging, read-only. **C1b:** one query at a time.
- **C2 — the writes** (1A's clear; the releases in 1.z / 1.u; 1.h's way-back reset; 1.s's put-back). **C2a (recommended):** each
  written inside `BEGIN; … ROLLBACK;` and run so on dev: the statement is parsed and its row counts are printed, nothing is
  kept; the runbook text then says `COMMIT`. **C2b:** written and reviewed only, never run.
- **C3 — backups instead of `mongoexport`.** **C3a (recommended):** `psql -c "\copy (SELECT … WHERE …) TO STDOUT WITH CSV HEADER"`
  to a file, put back with `\copy … FROM STDIN WITH CSV HEADER` — filters rows (one user's lots, P&L), one form for every
  section, child tables copied with their parent. **C3b:** `pg_dump --data-only --table` (whole tables only; 2.11 / 2.12 need
  one user's rows).
- **C4 — 1A's "staging only" guard** (was `db.getName() !== "it-staging"`; dev and staging are both `defaultdb`). **C4a
  (recommended):** the per-user clear is its own block, run only through staging's `PSQL()`. Its first statement refuses (`RAISE EXCEPTION`) unless the host name you pass
  as `-v host=…` equals staging's (`wealthlens-staging-aaaaaw.e.aivencloud.com`). The database name cannot be the guard,
  because dev and staging are both `defaultdb`.
  **C4b:** no guard; the text says staging only.
- **C5 — §1.s's Atlas record.** **C5a (recommended):** the Atlas table stays as the record of the Mongo era, headed so; the check
  and the restore steps name the PostgreSQL hosts (Neon's restore from history, Aiven's fork), each wording taken from
  `sources/2026-11-23-neon-postgresql.md` / `sources/2026-11-22-aiven-postgresql.md`, and what those notes do not say left
  `*not given*`. **C5b:** the Atlas table removed.
