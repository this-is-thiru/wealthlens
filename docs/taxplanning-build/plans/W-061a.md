## Plan for W-061a — a rule row may carry a definition (split from `W-061` by D-091)

**What this item is for (one sentence):** a rule version can state what an amount *is* — first, "the total
of one head's lines" — so the Act's definition of salary (s.16) is a row with provenance, a trace citation
and a rule for components to feed, rather than an untraced sum (`W-061` finding 1–2).

The design is `plans/W-061.md` C1a, approved there. This file records how it is built, following the
precedents `W-049a` (relief) and `W-050` (rounding).

### Design

- `rules/definition/RuleDefinition` — sealed; first and only permit **`HeadTotal(HeadCode head)`**: the
  amount is the total of that head's entered lines. A new definition shape is a new class and permit
  (D-091 made the family the seam).
- `RuleVersion` gains `Optional<RuleDefinition> definition` after `rounding`; the at-most-one check covers
  cap, relief, rounding **and** definition — a rule limits, relieves, rounds or defines, only one of them.
- JSON: `"definition": { "type": "HeadTotal", "head": "SALARIES" }`, read by `ShapeJson.definition`; an
  unknown type or head is refused, listing the known ones.
- `RuleJson`'s "means nothing" refusal counts a definition as content: its message becomes "has no cap,
  relief, rounding, definition or conditions". The two tests asserting the old wording are updated to it —
  the refusal is unchanged, its text names one more thing.
- The 14 `new RuleVersion(` sites (`RuleJson` + 8 test files) pass `Optional.empty()`.
- No row, pack, lock or `RuleIds` change: `W-061` authors the first definition.

### How I will verify

`./mvnw test -pl backend -Dtest=RuleJsonDefinitionTest,RuleJsonRoundingTest,RuleJsonReliefTest,PackJsonTest,RulePackLoadTest`,
then the unit tier.
- `RuleJsonDefinitionTest`: `HeadTotal` read with its head; loads without conditions; refused beside a cap
  and beside a rounding, naming both; unknown type and unknown head refused, listing the known.
- Bite probe: the definition dropped from the at-most-one check → the cap-and-definition test fails.
