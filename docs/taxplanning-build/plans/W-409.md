### Decisions (owner)

- **C1 — the fix.** **C1a (recommended, probed):** `application-copier.yaml` keeps the servlet application and opens no
  port: `server.port: -1` in place of `web-application-type: none`. Spring Boot documents `-1` as "create the web
  context, open no endpoint". The context is then the one every test already starts, so nothing serves while it copies.
  It is one line of configuration and no Java. **C1b:** `@ConditionalOnWebApplication` on `AuthConfig`, keeping no web
  context. That changes the security class every request passes through, and it is not probed.
- **C2 — the test.** **C2a (recommended):** `CopierStartIntegrationTest` (tag `integration`, `@Isolated`), with its own
  `mongo:8.0.4` replica set and `postgres:18`, both empty. It runs `new SpringApplicationBuilder(WealthLensApplication.class)
  .profiles("integration-test", "copier")` with the two URLs and `app.copier.written-zone=Asia/Kolkata`. It asserts that
  the run returns, that the context is closed (`CopierRun` calls `SpringApplication.exit`), and that no port is bound.
  Red before the fix: the run throws (`CorsConfigurationSource`). **C2b:** a test that runs the built jar as a child
  process. That is nearer to the owner's command but needs `package` before `test`, which the build does not do.
